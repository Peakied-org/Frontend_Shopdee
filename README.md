# Shopdee
Online Shopping website ( Cloning Shopee)

## Features

- Category
- Cart
- Order
- Login/Register
- Search Product
- Seller management
- Admin management
- Promotion

## Built with

**Frontend:** React ( Next.js )

**Backend** Java ( Springboot )

**Database:** MySql

**Deploy:** Vercel(Frontend) , Railway(Backend)
